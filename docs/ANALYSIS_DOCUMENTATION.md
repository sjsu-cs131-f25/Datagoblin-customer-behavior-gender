# Engineer 2: Advanced Analysis and Visualizations

## Overview
This phase focuses on advanced customer behavior analysis using the Datagoblin dataset.  
We applied data aggregation, segmentation, and visualization techniques to identify meaningful business insights.

## Code Files
The following Python scripts were used in this analysis:
- `advanced_analysis.py`: Performs detailed data aggregation and advanced analytics.
- `performance_optimization.py`: Improves computation performance and data processing efficiency.
- `visualizations.py`: Generates charts and visualizations from aggregated data.
- `ml_segmentation.py`: Applies machine learning models for customer segmentation.

## Data Sources
Data was retrieved from the Cloud Storage bucket `gs://datagoblin-customer-behavior/`, including:
- Aggregated metrics (age, value tiers, CLV, category affinity)
- Model outputs (performance results, segmentation profiles)

## Results
Sample CSV outputs were copied to:
`results/samples/`

Visualizations were downloaded to:
`visualizations/`

## Insights
- High-value customers exhibit strong loyalty and frequent purchases.
- Certain age segments show higher category affinity toward specific product lines.
- ML-based segmentation reveals distinct behavioral clusters useful for targeted marketing.

## Conclusion
This engineer phase successfully demonstrates the ability to use data pipelines, Google Cloud Storage, and analytics scripts to produce actionable insights and visualizations.  
All assets have been version-controlled and pushed to GitHub for reproducibility.
